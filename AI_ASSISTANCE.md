# AI Assistance Disclosure

## Transparency Statement

This project was built as a learning exercise to understand Generative AI and LangChain. During development, I used AI coding assistants (including Cursor AI, GitHub Copilot, and ChatGPT) to help with:

- **Code structure and patterns**: Understanding LangChain best practices
- **Debugging**: Fixing import errors, type issues, and runtime problems
- **Documentation**: Improving README clarity and structure
- **Learning**: Understanding concepts like RAG, vector embeddings, and LCEL

## What I Wrote vs. AI-Assisted

### Primarily My Work:
- Project architecture and design decisions
- Business logic and RAG pipeline implementation
- Portfolio integration and use case definition
- Testing and iteration based on actual results
- Understanding and explaining concepts in code comments

### AI-Assisted Areas:
- Initial boilerplate code structure
- TypeScript type definitions and error fixes
- Import path corrections for ES modules
- Documentation improvements
